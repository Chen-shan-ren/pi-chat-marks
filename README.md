# pi-chat-marks — pi 对话标记点列扩展

在 pi 终端的右侧（滚动条左边）显示一列点，每个点代表你的一次发送（用户消息），配合鼠标/键盘快速跳转和查看每次对话内容。

## ✨ 功能

| 功能 | 说明 |
|------|------|
| **右侧点列** | 每个点 = 你的一次发送，最新在最底部，与对话顺序一致；**最多显示 10 个点**，最新点绿色、普通点灰色 |
| **鼠标悬停** | 悬停的点**变大高亮**，编辑器上方实时显示该次发送的内容预览（时间 + 前 60 字），移开即消失 |
| **点击跳转** | 左键点击点 → 对话区**直接滚动跳转**到那条消息所在位置（基于渲染标记精确定位，支持重复消息） |
| **滚轮翻点** | 对话超过 10 次时，鼠标移到点列上滚动滚轮即可**上下滑动翻看**所有点，不影响对话区滚动 |
| **键盘索引** | `Ctrl+Alt+M` 或 `/marks` 打开对话索引：可搜索、`↑↓` 选择（点列同步高亮）、`Enter` 跳转 |
| **两种模式** | fullscreen 和 regular 模式都可用（鼠标交互在 fullscreen 下完整，regular 用键盘路径） |

## 📦 安装

```bash
# 1. 把 chat-marks.ts 复制到 pi 的全局扩展目录
cp chat-marks.ts ~/.pi/agent/extensions/

# 2. 重启 pi（或 /reload 后重启一次）
```

首次启动时扩展会自动给 pi 的 `tui-alt-screen.js` 打上鼠标钩子补丁（幂等，重启后生效）。

## 🖱️ 使用

```
鼠标悬停点    → 点变大 + 内容预览
左键点击点    → 跳转到该次发送
点列上滚轮    → 上下翻看点（对话超过 10 次时）
Ctrl+Alt+M   → 打开对话索引（键盘路径）
/marks        → 同上
```

## 🎯 特点

- **真正的鼠标交互**：通过 `onTerminalInput` + 自动补丁机制，在 pi 的鼠标事件处理之前拦截点列区域的点击/悬停/滚轮，不破坏原生的拖选复制、滚动条拖动
- **自动幂等补丁**：修改 `tui-alt-screen.js`（鼠标钩子、滚动条守卫、选择守卫三处），pi 升级覆盖文件后扩展会在下次加载时自动重新打补丁
- **精确跳转**：利用 pi 渲染层的 OSC133 标记 + 文本匹配定位消息行，支持消息重复场景（跳过前面相同前缀的消息）
- **不抢焦点**：点列是 nonCapturing overlay，打字、滚动、选择全部正常
- **无依赖**：纯 TypeScript 单文件，无需 npm 包

## ⚠️ 注意事项

- **悬停需要终端支持鼠标移动追踪**：Windows Terminal / WezTerm / Ghostty 等支持；经典 cmd（conhost）不支持移动追踪，悬停不可用，但**点击和滚轮可用**
- 扩展会修改 pi 安装目录下的 `tui-alt-screen.js`（自动、幂等），如不希望修改可删除扩展
- `Ctrl+Alt+M` 与终端快捷键冲突时可修改 `pi.registerShortcut` 中的键位
